# Kombin: protótipos de tela e requisitos

Documento de especificação do Kombin, app que recomenda lugares para comer e beber em Campo Grande pela ocasião.

**Integrantes:** Guilherme Lima Franco, Francisco Diogenes, Cauã Mariano, Luiz Felipe, Pedro Cano.

## Conteúdo

- Método e convenções (ISO/IEC/IEEE 29148, MoSCoW, IDs de requisitos)
- Requisitos gerais e regras de negócio
- História 1: cliente (7 telas)
- História 2: restaurante (4 telas)
- História 3: administração do Kombin (5 telas do painel proposto)
- Matriz de rastreabilidade e próximos passos

## Como abrir

Abra o `index.html` no navegador. Para publicar online, ative o GitHub Pages em Settings → Pages, com a branch `main` e a pasta `/ (root)`.

App em produção: https://kombin-seven.vercel.app · Código: https://github.com/Francoxkrs/kombin
